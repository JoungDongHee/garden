# 6강 - 선택 구조의 개념

## 선택 구조란?

- 특정 영역 내의 명령문을 **조건에 따라 실행 여부를 결정하는 구조**
- 조건이 참(`True`)이면 실행, 거짓(`False`)이면 실행되지 않음

---

## 선택 구조의 구문 형식

```python
if 불리언식:
    명령문1
    명령문2
```

### 특징

- **들여쓰기(indentation)**: 코드 블록을 구분하는 역할
- **코드 블록(block)**: 특정 동작을 수행하는 하나 이상의 명령문 집합
- **PEP-8 권고사항**: 들여쓰기는 공백 4칸 사용

---

## 불리언식 (Boolean Expression)

- 비교 연산자를 사용하여 **결과가 `True` 또는 `False`로 생성되는 표현식**

### 비교 연산자
| 연산자  | 수학적 표현 | 의미      |
|--------|-------------|-----------|
| <      | <           | 작다.     |
| <=     | ≤           | 작거나 같다. |
| >      | >           | 크다.     |
| >=     | ≥           | 크거나 같다. |
| ==     | =           | 같다.     |
| !=     | ≠           | 같지 않다. |

### 예제

```python
a = 10
b = 20

print(a < b)  # True
print(a == b) # False
print(a != b) # True
```

---

## 불리언 타입 (Boolean Type)

- **`True` / `False` 값만 표현할 수 있는 데이터 타입**
- **파이썬에서 `True` / `False`는 반드시 대문자로 시작**
- 비교 연산자의 결과는 **자동으로 불리언 타입**이 됨

### 예제

```python
print(type(True))   # <class 'bool'>
print(type(False))  # <class 'bool'>
print(5 > 3)        # True
```

## 논리 연산자 (Logical Operators)

- 참/거짓을 판별하는 **논리값(불리언 값)**을 연산하는 연산자
- **이항 연산자**: 두 개의 피연산자 사용
- **왼쪽 → 오른쪽 순서로 평가**

### 종류

|연산자|의미|
|---|---|
|`and`|논리곱 (둘 다 `True`여야 `True`)|
|`or`|논리합 (하나라도 `True`이면 `True`)|
|`not`|논리부정 (`True` ↔ `False` 반전)|

---

### `and` (논리곱)

- **두 값이 모두 `True`일 때만 `True` 반환**
- 하나라도 `False`이면 `False`

|b1|b2|b1 and b2|
|---|---|---|
|False|False|False|
|False|True|False|
|True|False|False|
|True|True|True|

#### 예제

```python
print(True and True)   # True
print(True and False)  # False
print(5 > 3 and 2 < 4) # True
```

---

### `or` (논리합)

- **하나라도 `True`이면 `True` 반환**
- 두 값이 모두 `False`일 때만 `False`

|b1|b2|b1 or b2|
|---|---|---|
|False|False|False|
|False|True|True|
|True|False|True|
|True|True|True|

#### 예제

```python
print(False or True)   # True
print(5 > 3 or 2 > 4)  # True
```

---

### `not` (논리부정)

- **논리값을 반전 (`True` ↔ `False`)**

|b1|not b1|
|---|---|
|False|True|
|True|False|

#### 예제

```python
print(not True)   # False
print(not False)  # True
print(not (5 > 3)) # False
```

## 단락 평가 (Short-Circuit Evaluation)

- **첫 번째 논리값만으로 결과가 결정되면 두 번째 논리값은 평가하지 않음**

#### 예제

```python
def test():
    print("함수 실행")
    return True

print(False and test())  # 함수 실행되지 않음
print(True or test())    # 함수 실행되지 않음
```

## 원뿔 계산 프로그램 (개선)

```python
rad = float(input("반지름 입력: "))
hei = float(input("높이 입력: "))

if rad > 0 and hei > 0:
    vol = (1/3) * 3.14 * rad**2 * hei
    suf = 3.14 * rad**2 + 3.14 * rad * hei
    print(f"부피: {vol:.2f}")
    print(f"겉넓이: {suf:.2f}")
else:
    print("반지름과 높이는 양수여야 합니다.")
```
