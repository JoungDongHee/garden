# 11강 - 모듈

## 모듈의 이해

### 모듈의 역할

- 프로그래밍 과정에서 코드의 재사용성을 높이고 유지보수를 용이하게 하는 역할을 수행

### 모듈의 개념

- 함수, 상수 또는 클래스를 모아놓은 집합체
- 하나의 `.py` 파일로 구성됨
    - **클래스**: 다른 모듈의 확장 가능
    - **함수**: 특정 작업을 처리
    - **상수(변수)**: 불변의 값
- **패키지**: 하위 패키지 및 모듈의 집합
- **라이브러리**: 패키지 및 모듈의 집합

#### 모듈 사용 구문

```python
import 모듈이름 [as 별칭]
```

- 파이썬 모듈을 프로그램 내부에서 사용할 수 있도록 네임스페이스에 추가하는 명령어
- 모듈 사용 예시:
    
    ```python
    모듈이름.변수
    모듈이름.함수()
    모듈이름.클래스
    ```
    

```python
from 모듈이름 import 메소드1[, 메소드2, 함수, 클래스]
from 모듈이름 import *
```

- 모듈 이름 없이 해당 모듈 내의 함수나 클래스를 직접 사용할 수 있음
- `*`을 사용하면 모듈 내의 모든 요소를 가져올 수 있음 (권장되지 않음)

## 네임스페이스의 이해

- 특정 객체를 이름을 통해 구분할 수 있는 범위
- **지역 네임스페이스 (Local Namespace)**: 함수 또는 메소드 내에서 사용되는 변수들의 공간
- **전역 네임스페이스 (Global Namespace)**: 모듈 전체에서 사용되는 변수들의 공간
- **빌트인 네임스페이스 (Built-in Namespace)**: 파이썬 내장 함수와 같은 기본 제공 요소가 속한 공간

## 모듈의 제거

- 모듈의 함수, 변수 등이 충돌할 경우 해당 모듈을 제거해야 할 수도 있음

```python
del 모듈이름
```

- 네임스페이스 내에서 모듈의 멤버를 제거함

## 원뿔 계산 클래스 개선

### 개선 전

```python
class Cone:
    def __init__(self, radius=20, height=30):
        if radius > 0 and height > 0:
            self.__r = radius
            self.__h = height

    def get_vol(self):
        return (1 / 3) * 3.14 * self.__r ** 2 * self.__h

    def get_surf(self):
        return 3.14 * self.__r ** 2 + 3.14 * self.__r * self.__h

cone = Cone(50, 10)
print(cone.get_vol())
print(cone.get_surf())
```

### 개선 후 (math 모듈 사용)

```python
import math  
  
class Cone:  
    def __init__(self, radius=20, height=30):  
        if radius > 0 and height > 0:  
            self.__r = radius  
            self.__h = height  
        else:  
            raise ValueError("Radius and height must be greater than 0")  
  
    def get_vol(self):  
        return (1 / 3) * math.pi * self.__r ** 2 * self.__h  
  
    def get_surf(self):  
        return math.pi * self.__r ** 2 + math.pi * self.__r * self.__h  
  
cone = Cone(50, 10)  
print(cone.get_vol())  
print(cone.get_surf())
```

## 예제 프로그램

### 로또 추첨 프로그램

```python
import random  
  
# 사용자 입력 처리: 공백을 제거하고 쉼표를 기준으로 분리  
guess_str = input("Guess a number between 1 and 45: ").split(",")  
guess_list = list()  
    
for i in guess_str:  
    guess_list.append(int(i))  # 공백 제거 후 정수로 변환  
  
# 랜덤 로또 번호 생성  
lotto_list = random.sample(range(1, 46), 6)  
print("예상 번호는", guess_list, "입니다.")  
print("추첨 번호는", lotto_list, "입니다.")  
  
# 일치하는 숫자 개수 카운트  
hit_count = 0  
for i in guess_list:  
    if i in lotto_list:  
        hit_count += 1  
  
# 맞힌 개수 출력  
print(f"축하합니다. {hit_count}개 맞혔습니다.")
```

### 삼각형 넓이 계산 프로그램

> [!info] **호도법이란?** 호도법(Radian Measure)은 각도를 호의 길이와 반지름의 비로 나타내는 방법입니다. 1라디안은 반지름과 같은 길이의 호를 포함하는 각도입니다.

```python
import math   
from math import sin  
  
a , b = 10,20  
  
area = 1/2 * a * b *sin(math.radians(60))  
  
print(area)
```

### 소수 찾기 프로그램

> [!info] **소수란?** 소수(Prime Number)는 1과 자기 자신만을 약수로 가지는 1보다 큰 자연수입니다. 예를 들어, 2, 3, 5, 7, 11 등은 소수입니다.

```python
import time  
  
start = time.time()  
  
def is_prime(x):  
    for i in range(2, x):  
        if x % i == 0:  
            return False  
    return True  
  
prime_count = 0  
  
for i in range(2, 500):  
    if is_prime(i):  
        prime_count += 1  
        print(i, end=". ")  
        print()  
  
end = time.time()  
  
finish_time = end - start  
print(finish_time,"seconds")
```
