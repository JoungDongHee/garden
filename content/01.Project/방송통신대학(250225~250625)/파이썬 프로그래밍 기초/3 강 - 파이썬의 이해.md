# 3강 - 파이썬의 이해

## 파이썬의 장단점

### 장점

- **역사 및 배경**
    - 파이썬은 **귀도 반 로섬(Guido van Rossum)**에 의해 1991년 개발되었다.
    - 원래는 분산 운영체제(아메바)의 시스템 관리를 위한 **쉘 스크립팅 언어**로 설계되었다.

> [!info] **쉘 스크립팅**  
> 쉘(Shell)은 사용자가 입력한 명령어를 해석하여 운영체제 내부 커널에 전달하는 명령 해석기 역할을 한다.  
> 쉘 스크립트는 명령어를 순차적으로 나열하여 운영체제의 동작을 자동화할 수 있도록 하는 방식이다.

- **다중 프로그래밍 패러다임 지원**
    - 파이썬은 **명령형 프로그래밍**, **절차적 프로그래밍**, **객체지향 프로그래밍**, **함수형 프로그래밍** 등 다양한 패러다임을 지원한다.
- **다목적 활용 가능**
    - 교육, 응용 프로그램, 웹 개발, 백엔드 시스템, 사물 인터넷(IoT) 등 다양한 분야에서 활용된다.
- **유지보수와 발전성**
    - 파이썬은 **파이썬 확장 제안(PEP, Python Enhancement Proposal)**을 통해 기능 개선 및 환경 개선이 이루어진다.
    - 예: [PEP 8 – 파이썬 스타일 가이드](https://peps.python.org/pep-0008/)
- **가독성이 뛰어난 문법**
    - 문법이 간결하고 자연어에 가까워 **의사 코드(pseudocode) 수준**으로 이해하기 쉽다.

### 단점

- **속도 저하**
    - C, Java 등으로 작성된 프로그램보다 실행 속도가 느리다.
- **단독 실행 애플리케이션 개발에 제약**
    - 원래 쉘 스크립트 언어로 개발되었기 때문에,
    - 모바일 애플리케이션과 같은 응용 프로그램 개발에 적합하지 않다.
    - 하지만, 일부 프레임워크(Kivy, PyQt 등)를 활용하면 GUI 애플리케이션 개발이 가능하다.

## 파이썬 실행 환경

- 파이썬은 **플랫폼 독립적**, **인터프리터 방식**, **객체지향적**, **동적 타이핑(dynamically typed)**, **대화형(interactive)** 언어이다.
- 파이썬 소스 코드는 실행 전에 **CPython 인터프리터**에 의해 **바이트 코드(bytecode)**로 변환된다.
- 바이트 코드는 **파이썬 가상 머신(PVM, Python Virtual Machine)**이 한 줄씩 기계어 코드로 변환하여 실행한다.

### 주요 개발 환경

- **IDLE**: 기본 제공되는 파이썬 개발 환경 (구문 강조, 자동 완성, 스마트 들여쓰기 지원)
- **Jupyter Notebook**: 웹 기반의 대화형 개발 환경 (데이터 분석 및 머신러닝에 활용)
- **Google Colab**: 구글 드라이브와 연동된 Jupyter Notebook 환경으로, 딥러닝 및 데이터 분석에 유용

> [!note] **컴파일러 유형**
> 
> 1. **셀프 호스팅 컴파일러**: 자기 자신의 언어로 작성된 컴파일러 (부트스트래핑 과정)
> 2. **소스-소스 컴파일러**: 한 프로그래밍 언어의 코드를 다른 언어의 코드로 변환하는 컴파일러

## 파이썬 프로그램 실행 과정

1. **소스 코드 작성 및 배포** (`.py` 파일)
2. **CPython 인터프리터가 소스 코드를 바이트 코드(`.pyc`)로 컴파일**
3. **파이썬 가상 머신(PVM)이 바이트 코드를 한 줄씩 실행**
4. **반복 실행 시 바이트 코드를 재사용하여 실행 속도 향상**
