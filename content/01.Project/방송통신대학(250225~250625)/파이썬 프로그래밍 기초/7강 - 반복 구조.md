# 7강 - 반복 구조

## 반복 구조의 개념

- 특정 영역의 명령문을 여러 번 실행하는 구조
- 반복 횟수를 조건에 따라 결정
- `loop`, `iterate`, `repeat` 용어가 혼용됨

## 반복 구조의 구문 형식

### 조건 제어 반복

```python
while 조건:
    코드블록
```

### 계수 제어 반복

- 반복 횟수를 미리 지정

```python
for 변수 in 시퀀스:
    코드블록
```

## 반복 구조의 설계 전략

1. 반복되어야 하는 명령 블록을 작성
2. 반복되어야 하는 명령문을 반복 구조로 작성
3. 반복 조건을 설정하고 반복을 제어하는 명령문 추가

### 반복 출력 프로그램

- `'저는 파이썬을 잘 다룰 수 있습니다.'`를 5번 출력하는 프로그램을 작성하시오.

#### `for` 문 사용

```python
msg = "저는 파이썬을 잘 다룰 수 있습니다."
for i in range(5):
    print(msg)
```

#### `while` 문 사용

```python
msg = "저는 파이썬을 잘 다룰 수 있습니다."
count = 1  
while count <= 5:
    print(msg)
    count += 1
```

## `n`까지의 합 계산 프로그램

```python
total = 0  
i = 1  
n = int(input("어디까지 더할까요? : "))  
while i <= n:
    total += i  
    i += 1  
print(total)
```

## 구구단 출력 프로그램

- 사용자가 입력한 단의 구구단 출력

```python
base = int(input("출력할 단을 입력하세요: "))  
i = 1  
while i < 10:  
    print(base, "*", i, "=", base * i)  
    i += 1
```

## 리스트

### 리스트의 개념

- 순서가 있는 값의 집합을 저장할 수 있는 데이터 타입
- 단일 식별자로 연속된 저장 공간 접근 가능
- 개별 원소의 값 수정, 추가, 삭제 가능
- 원소의 나열을 저장할 수 있는 시퀀스 타입 중 하나

### 리스트 구문 형식

- `[]`를 사용하여 표현
- 원소 구분은 콤마(`,`)로 구분

```python
hei = [1, 5, 14, 36, 26, 31]
```

### 인덱스 연산자

- 시퀀스 타입의 원소에 접근하는 연산자
- 접근 연산자 `[]` 사용
- 원소에 부여된 인덱스 번호로 접근 가능

## 계수 제어 반복의 사용

- 계수-제어 변수와 시퀀스를 사용
- 반복 시 계수-제어 변수에 시퀀스의 원소 할당

### 구문 형식

```python
for 변수 in 시퀀스:
    코드블록
```

### 원뿔 계산 프로그램 개선

- 반지름이 10이고 높이가 `[1, 5, 14, 36, 26, 31]`인 원뿔의 부피와 겉넓이를 각각 출력하시오.

```python
hei_list = [1, 5, 14, 36, 26, 31]  
rad = 10  
for h in hei_list:  
    vol = (1/3) * 3.14 * rad**2 * h  
    suf = 3.14 * rad**2 + 3.14 * rad * h  
    print(f"반지름 {rad}, 높이 {h}인 원뿔")  
    print(f"부피의 값은 {vol:.2f} 입니다.")  
    print(f"겉넓이의 값은 {suf:.2f} 입니다.")
```

## 리스트 생성 자동화

- 리스트 내 원소에 규칙성이 있는 경우 생성 자동화를 위해 `range` 함수 사용 가능
- `a`부터 `b`보다 작은 값까지 `k`씩 증가하여 시퀀스를 생성
- `a` 생략 시 기본값 `0`부터 시작
- `k` 생략 시 기본값 `1`씩 증가

```python
range(a, b, k)
```

### 원뿔 계산 프로그램 개선

- 반지름과 높이가 `(10,1)`, `(20,5)`, `(30,14)`인 원뿔의 부피와 겉넓이를 각각 출력하시오.
- `zip` 함수를 사용하여 두 개의 리스트 값을 하나로 엮어서 사용

```python
rad_list = range(10, 40, 10)  
hei_list = [1, 5, 14]  
  
for rad, hei in zip(rad_list, hei_list):  
    vol = (1/3) * 3.14 * rad**2 * hei  
    suf = 3.14 * rad**2 + 3.14 * rad * hei  
    print(f"반지름 {rad}, 높이 {hei}인 원뿔")  
    print(f"부피의 값은 {vol:.2f} 입니다.")  
    print(f"겉넓이의 값은 {suf:.2f} 입니다.")
```

## 중첩 반복 구조

- 반복 구조 내 다른 반복 구조를 내포한 형식

### 구문 형식

```python
for 변수1 in 시퀀스1:
    for 변수2 in 시퀀스2:
        코드블록
```

### 구구단 출력 프로그램 개선

- 구구단 표를 만들어서 출력
- `format` 함수를 사용하여 데이터를 양식에 맞춰 형식화
    - `">10s"`: 문자열(`s`)을 필드 폭 10만큼 우측 정렬(`>`)
    - `format("구구단표", ">10s")` → 문자열 왼쪽 정렬
    - `format(1234, "<10d")` → 정수 타입 기본값 우측 정렬
- `print`의 `end` 옵션을 사용하여 줄 바꿈 없이 연달아 출력

```python
print(format("구구단표", ">20s"))  
  
# 표 머리 출력  
print("  |", end="")  
for j in range(1, 10):  
    print(f" {j}", end="")  
print()  
print("-" * 32)  
  
# 구구단 표 출력  
for i in range(1, 10):  
    print(i, "|", end="")  
    for j in range(1, 10):  
        print(format(i * j, "3d"), end="")  
    print()
```
