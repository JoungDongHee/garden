# 2강 - 컴퓨터의 구성

## 하드웨어와 소프트웨어

### 컴퓨터의 구성 요소

컴퓨터는 `하드웨어`와 `소프트웨어`로 구분할 수 있다.

- **하드웨어**: 컴퓨터를 구성하고 있는 물리적 부품
- **소프트웨어**: 다양한 장치들을 동작시켜 특정 프로그램을 해결하는 프로그램

#### 하드웨어

하드웨어는 기능에 따라 다음과 같이 구분된다:

- 입력장치
- 기억&저장장치
- 제어장치
- 연산장치
- 출력장치

##### 폰 노이만 구조

![image.png](https://file-api.ksq9511.synology.me:5353/obsidian-image/20250226155551.png)



폰 노이만 구조는 사람의 문제 해결 능력을 모방하여 컴퓨터에 적용한 구조로, 컴퓨터 내부의 메모리에 데이터를 저장하고 이를 처리하는 구조를 의미한다. 범용적 컴퓨터에 크게 기여한 구조이다.

#### 소프트웨어

각각의 기능을 수행하는 하드웨어가 언제, 어떻게 동작하여 문제를 해결할 수 있는지 지시하는 명령어 집합이다.

##### 응용 소프트웨어

- 사용자의 업무나 목적에 맞게 문제를 해결하는 프로그램
- 예시: 한글, 엑셀 등

##### 시스템 소프트웨어

- 하드웨어를 제어, 관리하여 응용 소프트웨어를 실행할 수 있는 환경을 제공
- 예시: Windows, Linux, WAS(Web Application Server)

## 하드웨어의 이해

### 입력장치

명령과 데이터를 컴퓨터에 전달하는 장치로, 사람이 사용하는 언어를 컴퓨터가 이해할 수 있도록 2진수로 변환하는 역할을 한다.

- 예시: 키보드, 마우스, 스캐너, 터치 스크린

#### 특수 입력장치

- **마이오(Myo)**: 근전도 센서를 사용하여 사용자의 근육 움직임을 감지하고 제스처 기반 컨트롤을 제공하는 웨어러블 장치
- **립 모션(Leap Motion)**: 손의 움직임을 고해상도로 감지하여 제스처 기반 상호작용을 가능하게 하는 센서 기술

### 출력장치

정보 처리 결과를 인간이 인식 가능한 형태의 데이터로 변환하여 출력하는 장치이다.

- 예시: 모니터, 스피커, 프린터, 3D 프린터

#### 특수 출력장치

- **HUD (Head-Up Display)**: 차량의 앞 유리창에 정보를 표시하는 증강현실 장치
- **HMD (Head-Mounted Display)**: 머리에 착용하여 눈앞에 직접 영상을 제시하는 가상현실 장치

### 기억(저장) 장치

명령과 데이터를 저장하는 하드웨어이며, 역할에 따라 다음과 같이 구분된다.

- **주기억 장치** (RAM, ROM)
- **보조기억 장치** (하드디스크, 플로피 디스크)

|항목|기억장치 (주기억장치)|저장장치 (보조기억장치)|
|---|---|---|
|접근 속도|빠름|느림|
|제조 단가|높음|낮음|
|용량|작음|큼|
|전원 차단 시|ROM: 기억 내용 보존, RAM: 모든 내용 초기화|기억 내용 보존|

### 제어 및 연산장치

- 명령어와 데이터를 읽고 처리하는 장치로 **CPU**가 포함된다.
- **레지스터**: CPU 내부에서 초고속으로 동작하는 저장장치
- **제어 유닛**: 레지스터에서 명령을 읽고 ALU(연산 논리 유닛)에 전달
- **연산 논리 유닛(ALU)**: 제어 유닛에서 전달받은 데이터를 연산하여 레지스터에 전달

## 소프트웨어의 이해

소프트웨어는 하드웨어가 언제, 어떻게 동작하여 문제를 해결할 수 있는지를 절차적으로 지시하는 명령어 집합이다.

### 응용 소프트웨어

사용자의 목적에 맞게 문제를 해결하는 프로그램이다.

### 시스템 소프트웨어

다양한 장치들이 유기적으로 동작하여 특정 작업을 수행할 수 있도록 **환경을 조성**하는 프로그램이다.

- **운영체제 (커널)**: 하드웨어를 제어하여 사용자가 컴퓨터를 효율적으로 운영, 관리할 수 있도록 하는 소프트웨어
- **컴파일러**: 소스 코드를 기계어로 번역하는 소프트웨어
- **유틸리티**: 백신 프로그램, 포맷 소프트웨어 등 컴퓨터 관리에 도움을 주는 소프트웨어

### 운영체제

운영체제는 응용 소프트웨어가 효과적으로 작동할 수 있도록 환경을 조성하고, 컴퓨터의 자원을 효율적으로 관리하여 응용 프로그램에 자원을 할당하는 역할을 한다.

#### 주요 기능

##### 사용자 인터페이스 (UI)

- 컴퓨터와 사용자가 상호작용하는 방법을 제공
- **CLI (Command Line Interface)**, **GUI (Graphical User Interface)**

##### 프로세스 관리

- 실행되고 있는 프로그램(프로세스)을 관리
- 여러 프로그램이 동시에 실행될 때 한정된 자원을 효율적으로 배분

##### 네트워크 인터페이스

- 네트워크를 통해 데이터 교환을 가능하게 하는 환경을 제공
- 통신 장치 관리

##### 기억 저장 장치 관리

- 보조기억 장치(하드디스크)에 저장된 프로그램을 주기억 장치(RAM)로 적재하여 실행
- 주기억 장치는 보조기억 장치보다 용량이 작기 때문에 효율적인 관리가 필요
