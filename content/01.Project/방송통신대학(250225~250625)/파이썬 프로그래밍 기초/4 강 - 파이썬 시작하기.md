# 4강 - 파이썬 시작하기

## 숫자 (Number)

- **정수(Integer)** : 소수점이 없는 숫자
- **실수(Float)** : 소수점이 포함된 숫자

## 문자 (String)

- 유니코드 기반의 문자 또는 문자열을 지원
- 인용 부호 `" "` 또는 `' '` 를 사용하여 표현
- 문자가 하나든 여러 개든, 파이썬에서는 모두 문자열 타입으로 처리됨

```python
print("hello world")
```

> [!bug] **인용 부호 주의**  
> 한글이나 MS 워드 등에서 사용하는 특수 인용 부호 `” ”` 와 일반적인 인용 부호 `" "` 은 다르므로, 복사하여 실행할 때 유의해야 한다.

## 기본 연산자와 표현식 (Operators & Expressions)

- 피연산자와 연산자를 이용한 표현식은 파이썬 인터프리터에 의해 자동으로 계산됨
- 문자열끼리의 사칙연산은 문자를 합쳐서 표현 가능

```python
print("computer" + "science")  
# computerscience

print("computer" * 2)  
# computercomputer

print("Hello")  
print("World")  
# 여러 줄 출력 시 여러 번 print() 사용
# Hello
# World

```

## 문서화 (Documentation)

- **주석(Comment) 사용**
- 가독성 증대로 개발 속도 향상, 유지보수 용이
- **주석의 종류**
    - **한 줄 주석**: `#` 을 사용
    - **여러 줄 주석**: `"""` 또는 `'''` 세 개를 연속 사용

```python
# 이 것은 한 줄 주석    

'''   
이것은 여러 
줄 주석   
'''

```

## 데이터 저장 (Data Storage)

### 변수 (Variable)

- 프로그래밍에서 ` = ` 는 **"같다"**가 아니라 **대입 연산자(할당 연산자)**
- 데이터를 저장하고 재사용 가능하게 함
- 프로그램 실행 과정에서 값이 변경될 수 있는 **메모리 공간을 지정**
```python
rad = 20
```

- 변수를 사용하면 코드 유지보수 및 재사용성이 증가

```python
rad = 20 
hei = 30 
print(1 / 3 * 3.14 * rad * rad * hei) 
print(3.14 * rad * rad + 3.14 * rad * hei)
```

---

### 식별자 (Identifier)

- 프로그램 내부에서 **고유하게 사용할 수 있는 이름**
- 문자, 숫자, 밑줄(`_`)로 구성 가능
- 반드시 문자 또는 `_` 로 시작해야 함
- **예약어(Keyword)** 와 동일한 이름 사용 불가
- 길이 제한 없음

✅ 사용 가능: `volume`, `Surface`, `_50`, `x`, `y`, `__name__`  
❌ 사용 불가: `class`, `else`, `r+h`

```python
1+R = 20  # 오류 발생! 숫자로 시작하는 식별자는 사용할 수 없음
```

---

### 예약어 (Keyword)

- 파이썬이 문법적으로 사용하는 단어로, **사용자가 변수명으로 사용할 수 없음**

```python
class = 20  # 오류 발생! 'class'는 예약어이므로 변수명으로 사용할 수 없음
```

## 산술 연산자 (Arithmetic Operators)

![산술 연산자 이미지](https://file-api.ksq9511.synology.me:5353/obsidian-image/20250227001015.png)

- 피연산자에 대해 **산술 연산을 수행하는 기호**
- **단항 연산자**: 예) `-5`
- **이항 연산자**: 두 개의 피연산자 사용

### 특수 산술 연산자

- **정수 나눗셈 연산자 (`//`)**
    - `5 // 2` → 결과: `2`
- **나머지 연산자 (`%`)**
    - `10 % 3` → 결과: `1`

---

## 연산자 우선 순위 (Operator Precedence)

표현식 안에서 **여러 개의 연산자**가 사용될 경우, 계산되는 순서를 결정함

1. **괄호** 먼저 계산 `()`
2. **지수 연산** `**`
3. **곱셈, 나눗셈, 정수 나눗셈, 나머지 연산** `* / // %`
4. **덧셈, 뺄셈** `+ -`
5. **할당 연산자** ` = `

```python
avg = 1 // 3 * 3.14 * 20 ** 2 * (30 + 20 % 10)
```

## 파이썬 내장 함수 (Built-in Functions)

- **파이썬 인터프리터에서 기본적으로 제공하는 함수**
- **별도의 모듈 import 없이 사용 가능**
- 대표적인 내장 함수
    - `max()`, `min()`, `round()`, `abs()` 등
