# **1강 - 데이터와 정보**

## **데이터의 개념**

- 어떤 현상이나 사실에 대한 설명 또는 설명의 집합
- 관찰이나 실험, 조사를 통해 얻은 사실
- 이론을 세우는 데 기초가 되는 사실 또는 바탕이 되는 자료
- 관찰이나 측정을 통해 수치나 문자 형태로 표현할 수 있는 질적 또는 양적 값

### **데이터의 유형**

- **질적 데이터** - "붉다"와 같이 수치화되지 않은 특성을 표현
- **양적 데이터** - "3500도"와 같이 수치로 나타낼 수 있는 데이터

---

## **정보의 개념**

- 문제 해결이나 의사결정에 사용할 수 있는 데이터의 집합
- 데이터나 소식을 통해 얻은 지식이나 상태의 총량
- 관찰이나 측정을 통해 수집한 자료를 문제 해결에 도움이 되도록 정리한 지식
- 관찰이나 측정을 통해 얻은 데이터를 `정렬`, `합산`, `군집화` 등의 방법으로 가공하여 유용한 결과를 도출한 것

---

## **정보처리 과정**

1. **데이터 수집**: 현상을 관찰하고 측정하여 데이터를 생성
2. **데이터 저장**: 기록된 데이터는 문제 해결에 직접적으로 도움이 되지 않음
3. **데이터 가공**: 데이터를 정리, 변환, 분석하여 유의미한 `정보`로 변환
4. **정보 활용**: 변환된 정보를 통해 문제를 해결

#### **범주적 데이터**

- "옷의 사이즈"처럼 특정 기준으로 분류할 수 있는 데이터

## **컴퓨터의 정의**

- 입력된 데이터를 자동으로 처리하여 정보를 생성하는 기계

---

## **데이터의 기본 단위**

컴퓨터가 데이터를 저장하고 처리하기 위해서는 기본적인 단위가 필요하며, 이는 `비트(bit)`와 `바이트(byte)`로 구성된다.

- **비트(bit)**: 0과 1로 이루어진 `가장 작은 단위`
- **바이트(byte)**: 8개의 비트로 구성되며, `2^8 = 256가지`의 데이터를 표현 가능

---

## **컴퓨터가 2진법을 사용하는 이유**

![image.png](https://file-api.ksq9511.synology.me:5353/obsidian-image/20250226114827.png)



- 컴퓨터는 트랜지스터를 사용하여 데이터를 2진법 숫자로 표현하고 저장
- **트랜지스터의 상태**
    - 전류가 흐르는 상태 → `1`
    - 전류가 흐르지 않는 상태 → `0`
- 트랜지스터는 비트를 표현하기 위한 핵심 소자

## **아날로그와 디지털**

### **아날로그**

- 사물이나 개념을 `연속적인 물리량 값`으로 표현
- 질적 데이터 또는 양적 데이터로 표현 가능

### **디지털**

- 사물이나 개념을 `이산적인 값`으로 근사하여 표현
- 연속적인 데이터를 완전히 표현할 수 없고, 근사한 값으로만 표현 가능
- **양적 데이터**로 표현

## **ASCII 코드표**

- 미국 표준원(NIST)에서 개발한 문자 인코딩 표준을 **ASCII**라고 함
![image.png](https://file-api.ksq9511.synology.me:5353/obsidian-image/20250226114859.png)



> **NOTE**  
> 인코딩은 2진수로 이루어진 숫자를 문자와 매칭하는 체계를 의미

### **아스키 코드가 7비트만 사용하는 이유?**

- 초창기 컴퓨터 시스템의 저장 공간을 절약하기 위해 7비트(128개 문자)만 사용
- 이후 확장하여 8비트(256개 문자)로 발전

## **프로그램의 이해**

- 컴퓨터는 정보를 처리하는 방법과 과정을 자의적으로 결정할 수 없음
- 정해진 **프로그램**을 사용하여 정보를 처리함

### **프로그램이란?**

- 컴퓨터가 특정 작업을 자동으로 처리할 수 있도록 `처리 방법과 순서를 기술한 것`
- 여러 유형의 문제를 추상화하여 `알고리즘`을 구현한 결과물

---

## **알고리즘**

### **정렬 알고리즘 예시**

1. 2부터 10까지의 숫자가 무작위로 섞인 카드가 있다고 가정
2. 이를 오름차순으로 정렬하는 특정 `방법(알고리즘)`을 사용
3. **알고리즘의 정의**
    - 문제를 해결하기 위한 단계적 절차
    - 컴퓨터가 문제를 해결하도록 만드는 정형화된 명령어의 집합

#### **정렬 알고리즘 예제**

1. 정렬되지 않은 영역에서 가장 작은 숫자를 찾음
2. 맨 앞의 카드와 교환
3. 카드가 올바르게 정렬되었는지 확인

## **프로그래밍 언어**

- 컴퓨터는 사람의 언어를 이해할 수 없음
- 오직 `2진수`만 이해할 수 있기 때문에, **컴퓨터에게 명령을 내리기 위한 수단**이 필요

### **프로그래밍 언어의 분류**

![프로그래밍 언어 분류](https://file-api.ksq9511.synology.me:5353/obsidian-image/20250226112019.png)

#### **1세대 (기계어)**

- 0과 1로만 이루어진 언어

#### **2세대 (어셈블리어)**

- 영어 기반의 명령어 사용

#### **3세대 (고급 언어)**

- C, Java, Rust와 같이 `자연어와 유사한 형태`의 언어

---

## **프로그램의 실행**

- **고급언어**로 작성된 프로그램은 **기계어(0과 1)**로 변환되지 않으면 실행 불가능
- 변환을 수행하는 소프트웨어 사용
    - **컴파일러**: 소스코드를 한 번에 기계어로 변환
    - **인터프리터**: 코드를 한 줄씩 해석하며 실행
