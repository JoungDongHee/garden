## 5강 - 순차 구조

### 제어구조의 이해

#### 구조적 프로그래밍 패러다임

- 구조적 프로그래밍 패러다임은 절차적 프로그래밍 패러다임의 하위 개념이다.
- `goto` 문을 사용하지 않고 프로그램을 **3가지 제어 구조**만으로 구성하는 패러다임이다.
    1. **순차 구조**
    2. **선택 구조**
    3. **반복 구조**
- 프로그램 실행 흐름이 간결하고 작은 규모로 조직하기 쉬운 특징이 있다.

---

### 1. 순차 구조

- 실행의 흐름을 주어지는 **명령의 위치적 흐름**에 따라 수행하는 구조
    - 명령이 **위에서 아래로 흐르는 가장 직관적인 구조**
    - 첫 단계를 시작하면 마지막 단계까지 차례로 수행됨

### 2. 선택 구조

- 특정 영역 내의 명령문에 대한 **실행 여부**를 프로그램 실행 과정 중 결정하는 구조
    - 실행 여부는 **조건**에 따라 결정됨

### 3. 반복 구조

- 특정 영역의 명령문을 **여러 번 재실행**하는 구조
    - 반복 횟수는 **조건에 따라 결정됨**

---

## 프로그래밍 에러

- **설계 미숙**, **결함** 또는 **문법 오류**로 인해 프로그램이 의도한 대로 결과를 생성하지 못하는 문제
    - **구문 오류(Syntax Error)** : 문법 체계에 적합하지 않은 명령문 입력 시 발생
    - **실행 오류(Runtime Error)** : 논리적으로 실행이 불가능한 명령문 작성 시 발생
    - **의미 오류(Semantic Error)** : 의미적으로 잘못 해석되는 명령문 작성 시 발생

## 원뿔 계산 프로그램 개선

### 개선 사항

- `input()` 함수를 사용하여 사용자의 입력을 받아 계산
- `input()` 함수로 받은 데이터는 **문자열(str)**이므로, **숫자(int/float)**로 변환 필요

### 부피 공식

V=13πr2hV = \frac{1}{3} \pi r^2 hV=31​πr2h

- rrr : 밑면의 반지름
- hhh : 높이

### 겉넓이 공식

A=πr2+πrhA = \pi r^2 + \pi r hA=πr2+πrh

- rrr : 밑면의 반지름
- hhh : 모선의 길이

---

### 기존 코드
```python
# 반지름, 높이 값 할당  
rad = 20  
hei = 30  
  
# 부피 출력  
print(1/3 * 3.14 * rad**2 * hei)  
print(3.14 * rad**2 + 3.14 * rad * hei)

```

### 개선 코드
```python
# 반지름, 높이 값 입력 받기
rad = int(input("반지름 값을 입력하세요: "))  
hei = int(input("높이 값을 입력하세요: "))  
  
# 부피 및 겉넓이 계산
vol = (1/3) * 3.14 * rad**2 * hei  
suf = 3.14 * rad**2 + 3.14 * rad * hei  

# 결과 출력 (공백 제거)
print("부피의 값은 ", vol, " 입니다.", sep="")  
print("겉넓이의 값은 ", suf, " 입니다.", sep="")

```

---

### `print()` 함수 확장

- **여러 개의 데이터를 단일 함수로 출력 가능**
- **`,`(콤마)를 구분자로 하여 여러 파라미터 입력 가능**
    - 기본적으로 **데이터 사이에 공백**이 자동 추가됨
- `sep` 옵션을 사용하여 **공백 제거 또는 변경 가능**
```python
print("Hello", "World", sep="-")  # Hello-World
```
