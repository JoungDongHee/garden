### 📌 **안드로이드 주요 파일 및 폴더 정리**

## 1. **`java/MainActivity.java`**

- 안드로이드 앱에서 화면을 구성하는 **액티비티(Activity)** 를 정의하는 파일
- 앱 실행 시 가장 먼저 실행되는 코드가 포함됨

### 📌 **예제 코드**

```java
package com.example.myapp;

import android.os.Bundle;
import android.widget.TextView;
import androidx.appcompat.app.AppCompatActivity;

public class MainActivity extends AppCompatActivity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        // XML에서 정의한 TextView 찾기
        TextView textView = findViewById(R.id.textView);
        textView.setText("안녕하세요, 안드로이드!");
    }
}

```
---

## 2. **`build/R.java`**

- 앱이 동작하면서 참조하는 **자원(문자열, 이미지, 소리 등)의 ID를 정의**하는 파일
- `R.java`는 **개발자가 직접 수정할 수 없으며**, **AAPT(Android Asset Packaging Tool)** 에 의해 자동 생성됨

### 📌 **예제 코드**

```java
public final class R {
    public static final class layout {
        public static final int activity_main = 0x7f0a0001;
    }
    public static final class id {
        public static final int textView = 0x7f080067;
    }
}

```

---

## 3. **`res/drawable`**

- 앱에서 사용되는 **이미지 파일(png, jpg, gif 등)** 을 저장하는 폴더

### 📌 **사용 예시**

```xml
<ImageView
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:src="@drawable/logo"/>

```
---

## 4. **`res/layout/activity_main.xml`**

- `MainActivity.java`의 UI 레이아웃을 정의하는 XML 파일
- **실행 부분(Java)** 과 **데이터 부분(XML)** 을 분리하여 개발의 효율성을 높임

### 📌 **예제 코드**

```xml
<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    android:padding="16dp">

    <TextView
        android:id="@+id/textView"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Hello World!"
        android:textSize="20sp"/>

    <Button
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="클릭하세요"/>
</LinearLayout>

```

---

## 5. **`res/values/strings.xml`**

- 앱에서 사용하는 **문자열 리소스** 를 정의하는 파일
- 다국어 지원 및 코드 관리의 편리성을 위해 **XML로 문자열을 분리하여 저장**

### 📌 **예제 코드**


```xml
<resources>
    <string name="app_name">MyApp</string>
    <string name="welcome_message">안녕하세요, 안드로이드!</string>
    <string name="button_text">클릭하세요</string>
</resources>

```

---

## 6. **`AndroidManifest.xml`**

- 앱의 전반적인 정보를 담고 있으며, **구성 요소(액티비티, 서비스, 권한 등)를 정의**하는 파일
- 앱이 필요한 **API 레벨, 라이브러리 등 실행 환경 설정**을 포함

### 📌 **예제 코드**

```xml
<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.example.myapp">

    <application
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:theme="@style/Theme.MyApp">

        <!-- 앱의 첫 번째 실행 액티비티 -->
        <activity android:name=".MainActivity">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>

    </application>
</manifest>

```

## 📌 **Activity 개념**

- **Activity**: 하나의 안드로이드 앱 화면을 관리하는 컴포넌트
- `실행 부분(Java)` 과 `데이터 부분(XML)` 으로 분리되어 효율적인 개발 가능
- `R.java` 파일을 통해 실행 부분과 데이터 부분이 연결됨

---

## 📌 **안드로이드 주요 컴포넌트**

1. **Activity**
    
    - 하나의 스마트폰 화면을 관리하는 컴포넌트
2. **Service**
    
    - 스마트폰 화면과 별도로 **백그라운드에서 독립적으로 동작하는 컴포넌트**
3. **Broadcast Receiver**
    
    - 안드로이드 플랫폼에서 **이벤트(예: 네트워크 변경, 배터리 상태 등)를 감지하고 처리하는 컴포넌트**
4. **Content Provider**
    
    - 데이터를 체계적으로 관리하고 다른 앱이 활용할 수 있도록 **인터페이스를 제공하는 컴포넌트**

## 📌 **안드로이드 실행 원리**

![안드로이드 실행 원리](https://file-api.ksq9511.synology.me:5353/obsidian-image/20250227234512.png)

1. 개발자가 작성한 **Java 코드**는 **Java 컴파일러**를 통해 **Java 바이트 코드**로 변환됨
2. **안드로이드는 ART/Dalvik 가상머신**을 사용하여 바이트 코드를 실행
3. **DEX 변환기(DX Tool)** 를 이용하여 `.class` 파일을 **안드로이드 실행 포맷인 `.dex` 파일**로 변환
4. `.dex` 파일과 리소스 파일을 포함한 `.apk` 파일이 생성됨 (**패키징 과정**)
5. `.apk` 파일을 플랫폼에 설치하여 런타임에서 실행 가능

## 📌 **안드로이드 앱 배포 과정**

![안드로이드 앱 배포 과정](https://file-api.ksq9511.synology.me:5353/obsidian-image/20250227235456.png)

1. **앱 컴파일**
    - Java 코드 → `.class` 파일 생성
    - `.class` 파일 → `.dex` 파일 변환
2. **리소스 파일 처리**
    
    - XML 레이아웃 등 → `resources.arsc` 파일로 변환
    - `AndroidManifest.xml` 파일 포함
3. **패키징**
    
    - `.dex` 파일 + 리소스 파일 + `AndroidManifest.xml` 을 하나의 `.apk` 파일로 패키징
4. **서명(Signing)**
    
    - **디버그 키** (개발 중 테스트용) 또는 **릴리즈 키** (배포용) 사용
    - **보안 및 무결성 확인을 위해 서명 필수**
5. **배포**
    
    - 생성된 `.apk` 파일을 **구글 플레이 스토어 또는 기타 마켓**에 업로드
