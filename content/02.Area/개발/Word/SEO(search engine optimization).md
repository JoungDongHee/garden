# SEO 

search engine optimization 라는 의미로 검색엔진 최적화를 의미한다. 

구글 , 네이버 , 다음 등 에서는 다양한 알고리즘을 통해 사용자의 검색 을 분석하여 최적화된 결과를 보여주도록 설계가 되어 있다. 

그리고 이러한 검색엔진의 알고리즘 을 분석 활용하여 비즈니스 웹 이나 웹사이트 소유주 들 은 본인들의 웹 사이트를 검색엔진 사용자 의 최상위에 보여줘 트래픽 의 품질 과 양을 늘리는 행위 이다.


## Key World

가장 첫번째의 SEO 는 키워드 이다. 사용자는 검색을 할때 특정 키워드를 통해 검색을 할수있다. 

* 감기 빨리 낫는 법
* 여드름 약 구하는 방법
* 가성비 키보드 추천

위 에서 의 키워드는 **행위** 가 아닌 단어 그 자체 이다.  `감기` , `여드름 약` , `가성비 키보드` 와 같은 키워드를 사용하여 검색을 하고 있으며 이 단어들을 활용하여 글 을 작성 함 으로서 검색엔진의 상위에 본인 웹 사이트를 노출 시킬수 있다.

* 단 글 내부에 키워드를 너무 자주 노출 시킬 경우 검색엔진에서 봇 으로 인식을 하여 SEO 의 점수를 낮출수 있다.

## 페이지 속도

페이지 속도 는 사용자의 경험에 정말 중요한 역할을 하기 때문에 SEO 의 중요한 요소중 하나이다. 웹 사이트가 느리다면 사용자는 웹 사이트에 내용이 나오기도 전에 이탈을 할 것이며 이는 잠재 고객의 이탈 이기도 하다. 

그렇기 때문에 웹 페이지의 속도는 항상 최적화 하는 것이 중요하다. 웹 사이트를 최적화 하는 방법은 다양하지만 대표적인건 다음과 같다.

* 이미지 파일 용량 최적화 
* CSS , JavaScript 등 과 같은 코드의 최적화
* 글꼴 갯수 제한

과 같이 로딩 시간을 줄일수 있다. 자신의 웹 페이지 속도 측정은 구글 과 bing 에서 확인할수 있다.

* https://pagespeed.web.dev/?hl=ko 
* https://www.bing.com/webmasters/about?mkt=ko-kr

## 타이틀 태그 및 메타 설명을 작성

메타데이터 는 자신의 웹 페이지를 설명하기 위해 google 등 과 같은 검색엔진에 제공하는 데이터를 의미한다. 

검색 엔진의 봇 들은 이러한 메타데이터를 통해 데이터를 수집하여 검색엔진 사용자에게 최적의 정보를 제공하기 때문에 정말 중요한 요소중 하나로 작용한다.


### title 태그

가장 첫번째의 meta 태그로 title 에는 반드시 위에서 언급한 키워드가 들어가는 것이 좋다. 또한 대부분의 웹 사이트에서는 `<h1>` 태그 와 함께 동일하게 사용이 가능하다.

```html
<title>이 것은 제목입니다.<title>
```


### meta 태그

`<title>` 태그 이외의 부가적인 정보는 `<meta>` 태그를 사용하여 표현이 가능하다. 

예를들어 `name` 에 `description` 을 정의 함으로서 이 정보가 이 글에 대한 요약 정보라는 것을 담을수 있으며 `keywords` 를 활용하여 이 글에 대한 키워드 또한 표현이 가능하다.

```html
<meta
  name="description"
  content="이것은 이 글에 대한 설명입니다."
/>
```

```html
<meta name="keywords" content="HTML, CSS, JavaScript" />
```


## 글 내부에 링크를 삽입

글 내부에 `외부` 혹은 `내부` 로 이동할수 있는 링크를 연결함으로서 페이지 및 콘텐츠 간 연결된 네트워크를 더욱 쉽고 빠르게 구축할수 있다.

특히 내부 링크를 자주 활용해줘야 하는데 이는 **이 웹 사이트가 전문적으로 글을 다루고 있다** 라는 인식을 사용자 와 봇 에게 제공함 으로서 SEO 점수를 높일수 있다.



## 외부 링크 연결 에 대한 노력 


외부 링크 또한 본인의 웹 사이트의 SEO 점수를 높일수 있는 가장 좋은 방법중 하나이다. 

특히 본인이 주제로 다루고 있는 사이트 에서 본인 이 작성한 글이나 웹 사이트가 공유 되어 트래픽이 발생할때 점수가 가장 많이 오르게 되며 이는 결국 검색엔진 의 최상단 노출로도 이어지게 된다.
