# 객체지향 프로그래밍 (OOP)

**객체지향 프로그래밍** 프로그램을 단순히 데이터와 처리 방법으로 나누는 것이 아니라, 프로그램을 수많은 '객체(object)'라는 기본 단위로 나누고 이들의 상호 협력하면서 동작하는 프로그램을 의미한다.

**객체지향 프로그래밍** 은 프로그램을 **유연** 하고 **변경**이 용이하도록 설계하여 향후 유지보수나 수많은 사람과의 협력을 필요로 하는 대규모 프로젝트 개발에 많이 사용된다.

대표적인 객체지향 프로그래밍 언어는 JAVA 이며 이외에도 대부분의 프로그래밍 언어가 클래스(class) 문법을 통해 지원하고 있다.


## 5가지 원칙 **SOLID**

객체지향 프로그래밍 에는 5가지 원칙이 존재한다.

* SRP : 단일 책임 원칙
* [OCP](OCP(Open-Closed%20Principle)%20%EC%9B%90%EC%B9%99.md) : 개방 폐쇄 원칙
* LSP : 리스코프 치환 원칙
* ISP : 인터페이스 분리 원칙
* [DIP](DIP(Dependency%20Inversion%20Principle)%20-%20%EC%9D%98%EC%A1%B4%20%EA%B4%80%EA%B3%84%20%EC%97%AD%EC%A0%84%20%EC%9B%90%EC%B9%99.md) : 의존 역전 원칙
