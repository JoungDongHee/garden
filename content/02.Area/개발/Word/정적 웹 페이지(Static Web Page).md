# 정적 웹 페이지(Static Web Page)

[동적 웹 페이지(Dynamic Web Page)](%EB%8F%99%EC%A0%81%20%EC%9B%B9%20%ED%8E%98%EC%9D%B4%EC%A7%80(Dynamic%20Web%20Page).md) 와 정반대의 개념이다. 

문자 그대로 정적(靜的) 멈춰 있는 페이지 를 의미 한다.  이미 만들어진 HTML , 이미지 , JavaScript 등 을 서버를 거치지 않고 그대로 클라이언트에게 전송함으로서 서버의 부하를 줄일수 있다.

대표적으로 회사 소개 나 연혁 이 예시가 될수 있다. 

![image.png](https://file-api.ksq9511.synology.me:5353/obsidian-image/20241105235131.png)


위 와 화면은 이미 HTML 로 완성된 화면이며 웹 에서 데이터를 요청하지 않아도 되는 정적 웹 화면이다.


## 장점

- 서버에 요청을 보낼 필요가 없기 때문에 서버의 비용과 부하가 줄어듭니다.
- 이미 완성된 화면을 전송하기만 하면 되기 때문에 화면 로딩 속도가 빠릅니다.
- 유지보수가 상대적으로 쉽고 보안이 필요없기 때문에 보안 관리에도 용이하다.

## 단점

- 사용자가 직접 자원 관리를 해야 하므로, 화면 변경이 이루어질 경우 캐시 삭제 후 다시 화면을 받아야 합니다.
- 동적인 콘텐츠를 제공하기 어려우며, 사용자와의 상호작용이 제한적입니다.
