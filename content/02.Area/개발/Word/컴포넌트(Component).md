# 컴포넌트

컴포넌트는 현재 FrontEnd 에서 핵심으로 사용하는 개념으로 프로그래밍의 재사용성을 높이기 위해 각각의 기능을 독립된 모듈로서 설계를 하는 것을 의미한다.

![image.png](https://file-api.ksq9511.synology.me:5353/obsidian-image/20241104232436.png)



다음과 같이 네이버 화면이 있을 경우 각각 컴포넌트를 구성한다고 가정할 경우 다음과 같이 분류를 할수 있을 것이다.

1. NewComponenent : 전체 뉴스 를 볼수 있다.
2. ShopiongComponent : 쇼핑 정보 를 볼수 있다.
3. LoginComponent : 사용자의 로그인을 관리한다.

![제목 없음.png](https://file-api.ksq9511.synology.me:5353/obsidian-image/20241104233061.png)


그리고 각각의 **컴포넌트는 서로 독립된 객체로서 한가지의 기능만을 담당**한다. 이러한 각각의 컴포넌트가 모여 하나의 **큰 화면**을 구성하게 된다.

이렇게 독립된 객체로서 컴포넌트 를  구성을 하게 되면 향후 기능이 변경되거나 다른 것 으로 대체가 필요할 경우 부담없이 교체를 할수 있다.

현재 대부분의 FrontEnd 프레임워크(React.js , Vue.js) 등에서 활용되는 기술로 컴포넌트의 설계 에 따라 코드의 재사용성 과 유지 보수 등에 큰 영향을 줄수 있다.

# 결론

- **독립성**: 컴포넌트는 자신만의 기능과 데이터를 가지며, 다른 컴포넌트와 독립적으로 동작합니다.
- **재사용성**: 한 번 정의된 컴포넌트는 필요한 곳에서 계속 재사용될 수 있습니다.
- **유지보수성**: 컴포넌트 단위로 관리되기 때문에 변경 사항이 발생할 경우 해당 컴포넌트만 수정하면 됩니다.
