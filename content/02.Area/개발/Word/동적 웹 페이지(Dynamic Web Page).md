# 동적 웹 페이지(Dynamic Web Page)

[정적 웹 페이지(Static Web Page)](%EC%A0%95%EC%A0%81%20%EC%9B%B9%20%ED%8E%98%EC%9D%B4%EC%A7%80(Static%20Web%20Page).md) 와 는 반대되는 개념으로 이미 만들어진 HTML 이 아닌 서버로 부터 데이터를 전달 받고 이를 다시 가공하여 클라이언트 에 전송하는 페이지를 의미한다. 

우리가 이미 많이 보고 있는 네이버의 메인 화면 이라던가 인스타 등 끊임없이 데이터의 변경이 이뤄지고 이를 다시 화면에 반영하여 변경되는 화면들이 이 동적 웹 페이지에 해당한다.


![image.png](https://file-api.ksq9511.synology.me:5353/obsidian-image/20241106000048.png)


## 장점

- 사용자에게 다양한 최신 정보를 제공하고 가공하여 보여줄 수 있습니다.
- 사용자의 행동에 따라 실시간으로 페이지를 변경할 수 있어 상호작용성이 높습니다.

## 단점

- 정적 웹페이지에 비해 서버와의 추가적인 통신으로 인해 느린 속도가 발생할 수 있습니다.
- 서버의 데이터 처리와 전송 작업으로 인해 서버 부하가 발생할 수 있습니다.
- 보안 관리가 중요해지며 취약점 관리에 더 주의를 기울여야 합니다.
