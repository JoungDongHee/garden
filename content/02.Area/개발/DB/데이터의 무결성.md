# 데이터의 무결성


**데이터 무결성**은 데이터베이스에서 데이터의 **일관성, 정확성, 유효성, 안정성**이 유지되도록 보장하는 것을 의미합니다. 이는 데이터베이스의 신뢰성을 높이고, 데이터의 품질을 유지하는 데 핵심적인 역할을 합니다.

### 데이터 무결성의 주요 요소

1. **일관성 (Consistency)**
    - 데이터가 정해진 규칙과 제약 조건을 항상 준수하며, 시스템의 상태가 유효한 상태를 유지하는 것을 의미합니다.
    - 예: 은행 거래에서 돈을 송금하거나 입금한 후에도 시스템 내 모든 관련 데이터가 서로 모순 없이 정합성을 유지.
2. **정확성 (Accuracy)**
    - 데이터가 중복, 누락 또는 잘못된 값 없이 정확히 저장된 상태를 의미합니다.
    - 예: 고객 정보가 중복되지 않고, 각 고객이 고유한 ID를 갖는 것.
3. **유효성 (Validity)**
    - 입력된 데이터가 지정된 형식, 범위, 데이터 유형 등과 같은 유효성 조건을 만족하는 상태를 의미합니다.
    - 예: 나이를 입력할 때 음수나 잘못된 문자가 입력되지 않도록 제어.
4. **안정성 (Reliability)**
    - 데이터가 예기치 않은 오류나 손실로부터 보호되고, 시간이 지나도 신뢰성을 잃지 않는 상태를 의미합니다.
    - 예: 데이터베이스 장애 발생 시에도 데이터를 손실 없이 복구.


### 데이터 무결성이 중요한 이유

데이터 무결성은 우리가 일상적으로 사용하는 다양한 시스템에서 필수적입니다.  
예를 들어:

1. **은행 시스템에서의 무결성 보장**
    - 하나의 계좌에 대해 고유한 계좌 번호를 부여하는 것은 **정확성**
    - 잔액보다 큰 금액을 송금하지 못하도록 제한하는 것은 **유효성**
2. **전자상거래 시스템**
    - 상품 재고 정보가 정확히 유지되지 않으면, 같은 상품을 동시에 여러 고객이 구매할 경우 혼란이 생길 수 있습니다. 이는 **일관성**의 문제입니다.
